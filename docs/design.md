# 沙漏专注计时器 — 设计文档

日期：2026-10-22　状态：已定方向，实施中

## 1. 需求（来自与用户的问答）

- ASMR 放松向的番茄钟式专注小游戏，个人自用 / 作品展示；PC（独显）、Android、iPhone/iPad。
- 画面中心是精致的 3D 沙漏，风格：**极简现代**（无框玻璃、拉丝金属端盖、浅灰无缝背景、桌面焦散），参考 `docs/concepts/style-minimal.png`。
- 可设时间 1–60 分钟。沙量由时间决定，沙子全部流完恰好是设定时间。
- **沙子必须是真实物理，不能是表演**。沙子就是时钟：沙在流，时间就走；横放或倾斜导致断流，时间就停；时间永远等于流过的沙。
- 互动：翻转开始、拖拽环绕观察、倾斜/晃动影响沙子（手机陀螺仪 + 拖拽）、暂停 = 把沙漏横放。
- 沙的生成：调时间时沙粒在下方玻璃泡里由微光凝聚出来，然后真实落下堆积；减少时间时表层沙粒化光消散。
- 离开画面（锁屏、切后台）时时间继续走：回来时按离开时长转移沙量，再用真实物理沉降后显示。
- 声音：物理事件驱动的沙声、可选环境音、结束提示音、轻柔背景音乐。

## 2. 技术路线

纯 Web：TypeScript + Vite + **原生 WebGPU**（WGSL）。不用 Three.js：场景只有一个沙漏和摄影棚，玻璃需要解析光线追踪，沙子需要自定义的多通道渲染，物理在 compute shader 里跑；原生 WebGPU 控制最直接，也没有与框架互操作的麻烦。

只支持 WebGPU（iOS 26+），不支持时显示提示，不做 WebGL 降级。约束：每个着色器阶段的存储缓冲 ≤ 8 个，工作组 ≤ 256 线程，不依赖 subgroups 和 float 原子操作（Safari 和部分安卓不支持）。

## 3. 物理：多尺度真实模拟

### 3.1 物理尺度（真实沙漏的数值）

| 量 | 值 |
|---|---|
| 单个玻璃泡内腔高 H | 90 mm（瓶颈到端盖） |
| 玻璃泡最大内半径 R | 36 mm |
| 瓶颈孔径 D | 1.0 mm |
| 沙粒直径 d | 0.1 mm（细沙），颗粒密度 2650 kg/m³，堆积密度 ρb = 1550 kg/m³ |
| 重力 g | 9.81 m/s² |

### 3.2 瓶颈流量：Beverloo 定律

颗粒物从孔口流出的质量流量由 Beverloo 定律给出，与上方沙层高度无关，这正是沙漏能计时的物理原因：

  W = C · ρb · √g_axial · (D − k·d)^(5/2)，C = 0.58，k = 1.5

按上面的数值，W0 ≈ 59.3 mg/s。设定 T 分钟就生成 M = W0 · T 的沙：60 分钟约 213 g（约 138 cm³），1 分钟约 3.6 g。

g_axial 是有效重力（含晃动产生的惯性加速度）沿沙漏轴向的分量。倾斜时流量按 √cosθ 下降，横放时为 0，倒过来时换另一个泡向下流。所以暂停、倾斜、晃动对流量的影响都是同一条物理定律给出的。

### 3.3 三个尺度

1. **整体沙体：PBD 颗粒团**（Macklin 2014 统一粒子物理里的颗粒材料）。
   - 每个颗粒团是一个半径 r_c 的球，代表 ρb·(4/3πr_c³)/0.62 的沙。
   - 颗粒团之间、颗粒团与玻璃之间都是真实的接触碰撞，带静摩擦和动摩擦（μs≈0.55、μk≈0.45，玻璃 μ≈0.3）。
   - 自然形成约 33° 的休止角、上方塌陷漏斗、沙堆表面间歇性崩塌、翻转时的整团倾泻。
   - 用 shock propagation 质量缩放保证高沙柱稳定，低速颗粒休眠以消除抖动。
   - 子步数自适应：平时 4 步/帧，翻转冲击时按最大速度增加。
   - 分档：r_c = 0.75 mm（PC 高档，60 分钟约 4.8 万团）、1.0 mm（中档，约 2 万团）、1.25 mm（手机低档，约 1 万团）。
2. **瓶颈：孔口边界条件**。
   - 上游泡里，距孔口 R_cap 以内的颗粒团构成捕获区。
   - 每个子步按 W·Δt 从捕获区"抽走"沙量，离孔口最近的颗粒团先缩小、先消失，相当于这些沙进入孔口。
   - 抽走量不超过捕获区里实际有的沙：沙没压在孔口上（比如横放、或沙已流光）时流量自然为零或变小。
   - 抽走的质量全部变成下面的沙粒，质量严格守恒。
3. **沙流和飞溅：真实尺寸的沙粒，一比一数量**。
   - 每秒约 4.3 万粒 0.1 mm 沙粒从孔口下方射出，出口速度约 √(gD) ≈ 0.1 m/s，带少量横向扩散。
   - 沙粒在有效重力（含惯性力）下下落，与玻璃、沙堆做扫掠碰撞，低恢复系数反弹 0–2 次形成飞溅。
   - 停下后沉积进所在网格的累加器，长成新的颗粒团：从极小开始逐渐变大，满了再开一个。所以沙堆是连续长高的，不会突然冒出一团。

所有计算都在沙漏自身坐标系里进行。翻转、横放、倾斜、晃动，都表现为该坐标系里有效重力的旋转，加上惯性力（平移加速度、欧拉力、离心力、科里奥利力）。玻璃边界用解析的旋转体 SDF 表示，物理和渲染共用同一条轮廓曲线。

### 3.4 沙子时钟

- 时钟读数 = 已流过孔口的沙量 ÷ W0。剩余时间 = (M − 已流量) ÷ W0。
- 正常立着时，捕获区里的沙量远多于每步需要抽走的量，流量严格等于 W0，所以总时长严格等于 T。
- 只有最后几粒沙滑进孔口的瞬间流量会不足，和真沙漏一样。这个末尾延迟要实测，目标 < 1 秒。
- 每子步的抽走量按**墙钟时间**计算（W·帧实际时长/子步数）。即使设备掉帧导致模拟变慢，流过的沙量仍然与真实时间一致。
- 流量在 GPU 上逐子步计算。每帧把本帧流量读回 CPU，用双精度累加（f32 每帧相对误差约 1e-7）。

### 3.5 离开画面后的补算

1. 隐藏时记录墙钟时间和沙漏姿态。
2. 恢复时：若隐藏时是立着且在计时，转移量 = min(剩余, W0·Δt)。
3. 从上泡按漏斗流的顺序（中心、表层优先）移除对应的颗粒团；在下泡沙堆顶部上方，以"快速倾倒"的方式生成同等质量的颗粒团。
4. 不渲染地跑约 1–1.5 秒模拟时间，让两边都在真实物理下沉降，同时画面做一个柔和的"苏醒"过渡。

## 4. 渲染

- 沙漏总高约 19 cm，画面上占视口高度约 70%。
- **沙体**：
  1. 颗粒团用球体 impostor 渲染出深度和 id；
  2. 窄范围双边滤波把深度平滑成连续沙面，再由深度重建法线；
  3. 沙面细节用**锚定在颗粒团上的材质坐标**生成颗粒噪声和闪光（glint），所以纹理随沙一起流动，不会"游泳"；放大时能分辨出单粒沙。
- **沙粒**：沙流和飞溅的沙粒按真实尺寸投影，亚像素时用覆盖率混合，与沙面做深度测试，得到一条细而闪烁的沙线。
- **玻璃**：全屏合成通道里，对旋转体的内外两层轮廓做解析光线追踪，算出折射、反射、菲涅尔和全反射。瓶颈处是实心厚玻璃，有明显的透镜效果。泡内的沙通过屏幕空间沿折射光线步进去查找。
- **场景**：无缝浅灰摄影棚背景、桌面、拉丝金属端盖。程序化的环境光：顶部大柔光箱 + 侧面条形灯，在玻璃上形成竖条高光。
- **阴影和焦散**：对玻璃和沙做光子追踪，结果累加到桌面纹理上。姿态或沙量变化时增量更新。
- **后期**：色调映射、轻微暗角、抖动去色带。

## 5. 交互与状态机

`IDLE`（调时间：拖拽或滚轮，沙在下泡凝聚或消散）→ 翻转（1.2 s，绕水平轴旋转 180°）→ `RUNNING` ⇄ 横放 / 立起（`PAUSED`）→ 沙流完 → `FINISHED`（提示音）→ 回到 `IDLE`。

- 拖拽：从沙漏上开始拖是倾斜（弹簧阻尼回正，可以晃），从背景开始拖是环绕相机；双指或滚轮缩放（范围有限）。
- 陀螺仪：设置里开启，iOS 需要授权，把手机倾斜映射为沙漏的小角度倾斜。
- 重置：上泡剩余的沙化光消散，同等质量的沙在下泡凝聚。

## 6. 声音（全部程序化合成，不需要素材）

- 沙声：GPU 每帧统计沙粒撞沙堆、撞玻璃的次数和速度，以及崩塌活动量；AudioWorklet 用带通噪声微脉冲做颗粒合成。玻璃撞击加一点模态共鸣。
- 环境音：雨、壁炉、粉红噪声。背景音乐：慢速生成式氛围和弦加混响。结束提示：模态合成的颂钵音。各自独立开关和音量。

## 8. 验证

- **单元测试（vitest）**：轮廓的单调性、排空坡度（瓶颈到最宽处的壁面倾角 ≥ 50°）、容积 ≥ 60 分钟沙量的 1.35 倍、Beverloo 数值、时钟换算。
- **无头浏览器（SwiftShader WebGPU）**：
  - 用模拟时间跑小沙量（1–2 分钟的量），检查排空用时 = T ± 1 s，以及质量守恒（上 + 下 + 空中 = 总量）；
  - 截图检查画面。
- **真机**：帧率和观感需要在用户的 PC、Android、iPhone 上实测。需要一个 HTTPS 地址，部署方式待用户定。

## 9. 里程碑

1. **M0 物理核心**：轮廓、PBD 颗粒团、孔口、沙粒、沉积、时钟、调试渲染、计时精度测试。
2. **M1 画面**：沙面、沙粒、玻璃光追、场景、焦散、后期。
3. **M2 交互**：状态机、凝聚生成、翻转、横放、倾斜和晃动、相机、补算、UI。
4. **M3 声音**。
5. **M4 打磨**：性能分档、设置、真机调优。
